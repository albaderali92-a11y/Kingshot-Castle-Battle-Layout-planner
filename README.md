# Kingshot Castle Battle Layout Planner

This project is a static webpage for planning a Kingshot Castle Battle layout. It is ready to be hosted and shared as a normal website.

## Run locally

From the project folder:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000/index.html

## Share it

Because the app is a single static HTML file, it can be hosted on:

- GitHub Pages
- Netlify
- Vercel
- any web host that serves static files

The site entry point is `index.html`.
